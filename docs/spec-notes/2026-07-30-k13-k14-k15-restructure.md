# K13/K14/K15 restructure (owner rulings, 2026-07-30)

The K14 experiment had drifted from its intent ("flora tree", mirroring
K13's fauna tree) into a hybrid: the flora tree-of-life PLUS everything
world-facing (D0 productivity, B3 ground, B4 water column, datapack,
and the planned P7–P9 sim-diff). Rulings:

- **K13 (`exp/k13_treegen/`) = the unified tree-of-life engine.**
  Fauna content at `content/fauna/`, flora kit at `flora/` +
  `content/flora/`. K14's flora tree moved here unchanged in behavior
  (backbone/constraints/derive/metrics/content/naming/seeding); the
  k14 `model.py` re-export was deleted, importers use
  `exp.k13_treegen.model` directly. The flora tree JSONs live in
  `exp/k13_treegen/out/` (flat, k13 convention; `meta.generator` is
  now `k13_flora`). The parallel fauna/flora skeletons
  (backbone/metrics/derive, ~60–70% divergent) were NOT merged —
  a parameterized-by-kingdom dedupe is a possible follow-up, not
  part of this move.
- **K14 = world products derived from K11** (`exp/k14_worldprod/`).
  The former `exp/k14_flora/world/` flattened to top level:
  `derived.py` (P6/B2), `ground.py` (B3), `water.py` (B4),
  `datapack.py`, tests, `out/`. Pack header `generator` is now
  `k14_worldprod`. RNG stream identities containing the string "k14"
  (`seeding._ROOT_ENTITY`, `Stream(seed, "k14.ground.vents")`) were
  preserved deliberately — they are draw identities, not package refs.
- **K15 = sim-diff (slot reserved, no code yet).** Stress adapter,
  dispersal, cover, rounds (flora P7–P9 per B5, fauna A-rounds
  later); consumes K11 + K14 products + K13 trees. The shared stress
  math goes in `kernel/stress/` (B5 §2 placement note) — stress is
  organism-agnostic and belongs to no tree experiment.

Dependency direction is now one-way: K11 → K14 (world products) →
K15 (sim) ← K13 (trees).

K12 reminder: naming_corpora (deferred 2026-07-21) — treegen currently
carries its own nomenclature/stems; K12 would unify the corpora side
when it lands.

Verified at the move: `pytest exp/k13_treegen exp/k14_worldprod
exp/test_artifacts.py` = 291 passed (201 fauna + 22 flora + 62 world +
6 artifacts); viewer suites 14/14 + 30/30; seeds 1–3 world products
regenerated under the new module path; repo-wide grep for `k14_flora`
clean outside dated historical docs.
