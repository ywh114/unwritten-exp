# RFC: Procedural Fauna — Invented Phylogeny with Two-Tier Curation

**Status:** Draft RFC v0.1 (2026-07-21) · Requests comment, not yet normative
**Context:** Unwritten engine; refines Addendum A2 §4 (ecology). Does not modify A2 text; if accepted, A2 §4's "curated species library" gains a procedural tier and the "never LLM-invented" rule is restated as "never LLM-*composed*" (LLM names, never speciates).
**Feeds:** lab experiment C6 (ecology counters) — this RFC defines C6's species-table input.

---

## 1. Problem

A2 §4 requires many critters, biome-correct, ecologically correct, and forbids LLM species invention (P5: charismatic-megafauna convergence). A fully hand-curated library large enough to feel alive is an authoring bottleneck; a fully LLM-generated one is a naming-problem failure. We need a middle path that is cheap to build, structurally correct, and interesting.

## 2. Proposal in one paragraph

Author a small **invented cladogram** by hand (2–3 root body plans, ~8–15 major clades, one YAML file). All species are generated by **clade-conditional sampling**: a species is a clade template plus sampled parameter deltas, so phylogenetic correctness is *definitional*, not validated. Curation is split into two tiers: a small set of hand-placed **anchor fauna** (recognizable megafauna — horses and horse-kin, livestock, apex predators) and unlimited **background fauna** (raw generator output — mice, bugs, fish — accepted without familiarity pressure). A separate **naming layer** (LLM/curated, three grades) supplies common names; scientific consistency comes from the tree, never from names.

## 3. Design

### 3.1 The cladogram (hand-authored, small)

- One YAML file. 2–3 root body plans; ~8–15 major clades; depth capped at ~3 levels (root → clade → species). **Cap the depth and stop** — correctness beyond that is edge-case fiddling with no player payoff.
- Each clade: name, diagnostic trait set (limb plan, metabolism, covering, mouthparts), parameter ranges (size, diet, social unit, activity pattern, habitat requirements, wariness, mobility class — the A2 §4 schema), and biome affinities (weights consumed directly by ecology packs).
- **Growth rule:** diversity increases by speciating *within* clades, never by appending new roots ad hoc. Appended roots are how an invented phylogeny degrades into a list.

### 3.2 Speciation (procedural, hash-seeded)

- Species = clade template + deltas sampled from clade-conditional distributions, via the K1 hashrng machinery (deterministic, replay-safe).
- Correctness is structural: a mustelid-analog sampler cannot emit a grazer; diet↔habitat↔size consistency is enforced by the sampler's conditionals, not by a validation pass after the fact.
- **Interestingness rule:** allow *mosaic sampling* — one clade's body plan with another's ecology (grazing feathered hexapod) — as a low-probability event. Reads as deep evolutionary history; costs one extra sampling rule.
- Abundance: sampled from trophic-pyramid ratios per biome, feeding A2 §4's ratio-sanity rule directly.

### 3.3 Tier 1 — anchor fauna (curated)

- ~20–40 hand-written species covering familiar ecological roles: mounts and their kin (a horse, plus flavor relatives — shaggy steppe pony, big-headed forest horse, striped ass-analog), livestock, big grazers, apex predators, one or two uncanny specials.
- Anchors are **hand-placed on the cladogram**: their clade membership and parameters are authored so they read as familiar. The generator then speciates siblings and cousins around each anchor, so every curated animal sits in a lived-in tree.
- This is where player-facing quality lives; ~30 hand-authored entries are cheaper than tuning a generator to produce 30 good ones.

### 3.4 Tier 2 — background fauna (raw generator output)

- Small-clade speciation runs free: rodent-analogs, insect-analogs, fish-analogs. **Zero familiarity pressure; whatever falls out is canon.**
- Every background species is a real record: clade, diet, habitat, abundance, activity schedule. Curation cost ≈ zero — the only quality gate is the structural consistency already in the sampler, not taste.
- Populations remain counters + render-boundary samples per A2 §4; most background species are never individually examined.

### 3.5 Naming layer (three grades, all cheap)

Names are decoupled from the taxonomy; the LLM names sampled species, never composes them (P5 holds).

1. **Named** — folk names from metadata ("small burrowing granivore, ash-dark coat, commensal near forges" → *coal-rat*). One batched LLM pass; human veto, not authoring.
2. **Nickname-grade** — name encodes salient parameters (*great grey mouse*: "great" = size percentile, "grey" = coat, "mouse" = folk label). Near-mechanical generation from the record; ROUS-class names fall out naturally.
3. **Unnamed** — "strange insect." Metadata is still real, so the engine can track, hunt, and re-recognize it ("the same strange insect as last week") with no ledger entry — consistency comes from the record.

**Folk labels vs. clade names:** keep a small folk-label vocabulary ("mouse," "rat," "bug") separate from scientific clade names. Folk labels follow *appearance*; clades follow *descent*. A gliding arboreal rodent-analog is still called a "mouse" by NPCs — the mismatch between folk label and clade is exactly what makes an invented taxonomy feel real.

### 3.6 Promotion (soft tier boundary)

A background species that accrues player attention promotes to anchor treatment: it gets a proper name, possibly curated relatives, and promise-backed presence. This is the existing chimera/promotion path (A1 §7, A2 §4) applied at species level rather than individual level. The white stag and the coal-rat are the same mechanism at different ranks.

## 4. Integration with existing machinery

| Existing piece | Role here |
|---|---|
| K1 hashrng | seeded speciation sampling; replay-safe bestiary |
| A2 §4 ecology packs | consume clade biome-affinity weights and abundance ratios directly |
| A2 §4 ratio-sanity | validated against sampled abundances at commit time |
| A1 §7 promotion | species-level promotion path (§3.6) |
| Gossip/wiki | scarcity rumors, named-creature facts; unnamed species stay record-only |
| C6 lab experiment | this RFC defines its species-table input |

## 5. Non-goals

- Earth-taxonomy matching or real-world phylogenetic accuracy (explicitly dropped; only *internal* consistency matters).
- Deep taxonomic correctness below ~3 levels.
- LLM-composed species, locomotion invention, or trophic dynamics beyond A2's ratio rules.
- Curating background fauna. Taste is not a quality gate for Tier 2.

## 6. Cost estimate

Cladogram YAML + anchor list: a weekend of authoring. Speciation sampler + naming pass: 1–2 days of code on top of K1. This is deliberately an RFC-sized feature, not a milestone.

## 7. Open questions

1. How many root body plans before the world stops feeling coherent — is 3 the right cap?
2. Mosaic-sampling probability: rare spice or a dial per biome?
3. Folk-label vocabulary: hand-authored list, or mined from anchor-species resemblances?
4. Should unnamed-species re-recognition ("same strange insect") be exposed to the player, or stay an internal consistency property?
5. Species-level promotion: automatic on attention threshold, or orchestrator-discretionary with a drama-budget cost?

## 8. Failure modes to watch

- **Backbone creep:** adding roots instead of speciating (§3.1 growth rule exists to prevent this).
- **Familiarity bleed:** Tier 2 species quietly getting curated "because this one matters" — if it matters, promote it explicitly (§3.6), don't hand-tune it in place.
- **LLM naming drift:** name batches converging to generic fantasy names; counter is the metadata-grounded prompt and human veto, same as A2 §10's guard.
